# The Local Edit

Ein persönlicher, kartenzentrierter Guide für Rüttenscheid und Umgebung.

## Idee

Nicht nur Branchen sammeln, sondern Orte räumlich und nach Eigenschaften erfassbar machen: Innenhof, Garten, ruhig, lange sitzen, Kaffee, Essen, Feinkost, praktisch und später weitere persönliche Merkmale.

## Technik

- statisches HTML/CSS/JavaScript
- Leaflet
- OpenStreetMap
- JSON als Datengrundlage
- GitHub Pages als Hosting

## Datenschutz

Keine Privatadresse im Repository. Für spätere Distanzangaben wird eine Feuerwache als neutraler Bezugspunkt verwendet.

## Datenstatus

Die Ortsdaten sind aktuell ein erster Prototyp. Namen und Auswahl stammen unter anderem aus der Branchenkarte von Rüttenscheid.de; Koordinaten sind in dieser frühen Version noch als Prototypdaten markiert und werden schrittweise verifiziert.
